TUFT DETECTOR - QUICK COMMANDS
==============================

Run these commands from the project folder.


1. SET UP (once)
---------------

cd "/Users/aryandesai/Downloads/Projects/Tufting-Visual-Detection-System"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r Requirements.txt -r Requirements-train.txt
python -m pip install "git+https://github.com/facebookresearch/sam2.git"


2. MAKE TRAINING LABELS
-----------------------

Create draft labels only inside the vehicle surface. The polygon selector is
per image: click around the instrumented wing/door/window, press Enter to
confirm, and use right-click to undo a point. Do not include sky, ground, or
the garage floor in the polygon. Start a clean dataset so the earlier
background-heavy drafts in data/new_review are not mixed in:

python -m tools.autolabel --images Images/tuft4.jpg --out data/vehicle_review --select-roi
python -m tools.autolabel --images Images/tufts1.jpeg --out data/vehicle_review --select-roi
python -m tools.autolabel --images Images/tufts2.jpg --out data/vehicle_review --select-roi
python -m tools.autolabel --images Images/tufts5.png --out data/vehicle_review --select-roi

tufts3.jpg and tufts6.jpg are AVIF files despite their .jpg names. Convert them
to real JPEG files before passing them to the OpenCV tools:

mkdir -p outputs/avif-converted
sips -s format jpeg Images/tufts3.jpg --out outputs/avif-converted/tufts3.jpeg
sips -s format jpeg Images/tufts6.jpg --out outputs/avif-converted/tufts6.jpeg
python -m tools.autolabel --images outputs/avif-converted/tufts3.jpeg --out data/vehicle_review --select-roi
python -m tools.autolabel --images outputs/avif-converted/tufts6.jpeg --out data/vehicle_review --select-roi

Review labels at a larger display scale:

python -m tools.review_labels --data data/vehicle_review --scale 0.85 --select-only

In select-only mode every proposal starts unselected. Click a tuft proposal to
select its whole mask, and click again to deselect it. Only selected tufts are
saved as positive labels:

In the review window: click to select/deselect a tuft, shift-click to flip direction,
right-drag to reject a box, m to paint missed tuft-mask pixels, e to erase
pixels, - and + to change brush size, v to return to click-selection, u to undo,
and s to save and continue. The tuft proposals are shown as a green mask, not
vectors; press a to toggle vector arrows. Brush edits add tuft-mask labels only;
they do not invent root-direction labels. Review every tile and remove any
proposals that are not on the instrumented vehicle surface.


3. TRAIN THE U-NET
------------------

Make supplemental synthetic training examples:

python -m tools.make_synthetic_dataset --out data/synthetic --count 60

Train using the reviewed photos and synthetic examples. This writes a separate
candidate checkpoint so an existing model is not overwritten:

python tools/train_unet.py --data data/real_review data/vehicle_review --synthetic data/synthetic --out models/tuft_unet_vehicle.pt --epochs 50 --epoch-size 400 --batch 8 --size 256 --base 16 --device mps


4. RUN AN IMAGE AND OPEN THE RESULT
-----------------------------------

Replace sample_tufts1.jpg with the image name in Images/:

python main.py --image Images/sample_tufts1.jpg --backend unet --weights models/tuft_unet_vehicle.pt --select-roi --outdir output --save-mask

For inference, --select-roi selects a rectangular region of the vehicle to
exclude surrounding background from tuft/vector detection. Use the threshold
reported in the new checkpoint's training metadata if you tune it.

Open the newest annotated image:

open "$(ls -t output/*_annotated.png | head -n 1)"

The annotated image, mask, and vector CSV are saved in output/.
The detector cannot promise a fixed accuracy on arbitrary images; measure recall
and false positives against reviewed photos held out from training.
